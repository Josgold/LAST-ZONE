# LAST ZONE

A 3D Android battle-royale game prototype built with **Godot 4**.

## Current prototype
- 3D test arena with a ground plane and simple scenery
- Third-person player capsule and follow camera
- Keyboard movement for desktop testing (WASD + Space)
- On-screen movement and jump buttons for touch testing

## Open the project
1. Install Godot 4.x on a Windows, Linux, or macOS computer.
2. Download or clone this repository.
3. In Godot, choose **Import** and select the `project.godot` file.
4. Open the project and press **F6** or **F5** to run.

## Development status
This is an early offline prototype. Online multiplayer, matchmaking, player accounts, inventory, a full island map, safe-zone logic, and Android export configuration are not implemented yet.

## Planned milestones
1. Improve player movement and add touch camera controls.
2. Build a larger island test map and interactive objects.
3. Add game-state systems and non-graphic combat mechanics.
4. Design secure online rooms and authoritative multiplayer networking.
5. Optimize and export an Android build.
